# CS 61A: The Game of Hog

A Python implementation of the dice game **Hog**, based on UC Berkeley's **CS 61A: Structure and Interpretation of Computer Programs**.

---

## 📌 Attribution & Scope

- **My Implementation:** All game logic, rule mechanics, and strategic simulations were implemented by me strictly in `hog.py`.
- **Course Starter Code:** The accompanying files (`dice.py`, `hog_gui.py`, `hog_ui.py`, `default_graphics.py`, `ucb.py`, and the assets in `gui-files/`) were authored by UC Berkeley's CS 61A instructional team. They are included here solely to provide the graphical interface and dependencies needed to run the game locally.

---

## 🎲 About the Game

Hog is a two-player turn-based dice game where players compete to reach 100 points. On each turn, a player decides how many dice to roll (0 to 10), balancing risk and reward under special scoring rules (such as Sow Sad, Boar Brawl, and Sus Fuss).
